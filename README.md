### 封锁行动

1. 与队友「回声」从一期商场出发，接入终端取得密钥。
2. 穿过既有连廊与实体楼梯，到酒店 2F 取回情报。
3. 选择公寓 B1 车辆接应，或沿实体楼梯/电梯前往酒店屋顶直升机接应；清理威胁并守住撤离区，随后登车驶离或登机起飞。

包含 7 名侦察、突击和装甲敌人，具有视野、听声调查、警戒追击、弹匣换弹及战术移动；玩家可切换两把枪及连发模式，瞄准、蹲伏、冲刺、跳跃、搜集补给和急救。冲刺有耐力、压低持枪姿态与明显手臂摆动，跳跃有起跳、下落和落地反馈。回声支持跟随、守点、掩护和救援；本地 AI 自行移动和交战，无需 API Key。敌我射击受墙体与楼层遮挡约束，移动使用原园区碰撞与连续楼梯。

SMG-45、Desert Eagle、手套与衣袖均来自免费可再分发的带贴图模型。SMG 保留源骨骼换弹动画，手枪使用真实分件制作弹匣、套筒动作；切枪先收起旧枪再拔出新枪。作者、许可和修改说明可在游戏暂停菜单查看，完整记录见[素材来源](docs/fps-asset-sources.md)。

### 手机操作

- 左摇杆移动，右侧空白区域拖动视角；按住开火/冲刺，轻点跳跃、瞄准、蹲伏、换弹、切枪和急救。
- 靠近任务点后交互；取得情报后可切换车辆/直升机目标。撤离区自动计时，离开会重置，附近威胁会阻止撤离。靠近电梯可选择楼层并观看乘梯过程。
- 点击队友状态选择指令；暂停菜单也能输入「跟我走」「守住这里」「掩护我」。
- 暂停 → 操作设置：调整按钮大小、透明度、瞄准灵敏度、反转 Y 轴与音效。自定义布局可拖动按钮，横屏和竖屏分别保存。
- 暂停或切换到后台会停止游戏输入；返回封面后再选模式会释放原页面的 3D 场景。
- 普通导览保留玻璃底栏和「净览」隐藏界面。

桌面兼容 WASD / 方向键移动、鼠标视角与开火、R 换弹、Q 切枪、E 交互、H 急救、C 蹲伏、Shift 冲刺、Space 跳跃、F 射击模式、T 撤离路线、Esc 暂停。

## 手机负载控制

在线封面只有二维图片和小型入口脚本，选择模式之前不创建 WebGL，也不下载枪械和建筑模型。进入 FPS 后按需载入战斗模块与 5.75 MiB 枪械资产；导览不会加载枪械。

FPS 固定使用流畅画质，关闭动态阴影、泛光、普通人群与交通，限制清晰度及 30 fps 渲染频率；只保留任务所需楼层，客房按访问楼层缓存。两种模式共用原套房和 PBR 贴图；三套住宅模型仅由探索模式下载，FPS 不请求这些模型。第一人称枪械与世界共用一个 WebGLRenderer。

浏览器的 iPhone 尺寸、触屏模拟、完整任务及构建检查见[本轮 QA](docs/qa-2026-10-20-campus-fps.md)及 [FPS 实走](docs/fps-expansion-qa.md)。这些检查不等同于实体 iPhone 的帧率、温升和长时间内存验收。

2026-10-28 导览启动修复：完整地图保持，套房和三套住宅改为访问客房层时加载，失败可重试；释放临时画布并减少几何缓冲复制峰值。排查、265 项测试及手机浏览器模拟结果见[最新启动修复报告](docs/qa-2026-10-28-tour-recovery.md)。

一期扩建同时接入商业楼层流式构建：总览不建立 40 个地上商业楼层的室内；手机最多缓存 4 层，桌面常规 6 层、爆炸视图最多 8 层。接近连廊提前构建对应目的地，旧层的私有几何、贴图、动态回调和灯光回调实际释放。楼板、立面、连续楼梯、地库及地铁结构保持，精装住宅继续使用独立的 3 层缓存。[扩建实施与验收](docs/qa-2026-10-28-p1-expansion.md)记录本地与线上结果。

## 本地开发与离线版

建议 Node.js 20+、npm、Python 3：

```sh
npm ci
npm run build
npm run serve
```

打开 http://127.0.0.1:5174/。修改源码后重新构建；不要手改 `index.html` 或 `dist/`。

`dist/mall.html` 是资源内嵌的双模式离线版，可下载后在新版桌面浏览器中直接打开。手机优先使用 HTTPS 在线站点；iOS 文件预览不能代替 Safari 网页运行环境。离线版的本地 AI、枪械和任务不需要模型 API。
