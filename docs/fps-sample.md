# 云澜汇手机 FPS 小样 · 2026-10-20

## 玩法与范围

`src/fps/mission-layout.js` 是任务、出生点、7 名敌人、队友、目标和战术物件的同源数据。任务从 P1-1F 出发，经 H-1F 实体消防梯到 H-2F，随后在两条路线间选择：经 P1 扶梯和地下公共走道到 A-B1 接应车，或沿酒店 3F 消防梯 / 玻璃电梯到 H-RF 直升机。楼梯连续步行，电梯有真实进舱、关门、升降、开门和出舱过程。

探索模式已恢复完整园区：一期、二期、三期、四栋住宅、地铁、公园、云环桥、西侧停车场和周边城市，198 个目录楼层。只有 FPS 在创建渲染对象之前裁到 P1/H/A：18 个场景楼层，其中 17 个可走、一期 12m 顶盖封闭；酒店和公寓保留 1F 大堂、2F/3F 共 40 间套房，以及 13.3m 的可达 RF。探索模式的酒店/公寓共 380 间套房，首层独立改成大堂。原用户模型保持比例。

玩家有 SMG-45（25 发弹匣）与 Desert Eagle（7 发弹匣）、有限备弹及两个急救包。任务点恢复少量生命与备弹。前两个目标必须在范围内、视线无遮挡时完成读取；没有情报不能提前撤离。拿齐两份情报后，公寓 B1 接应车守住 8 秒，或酒店 RF 直升机守住 11 秒；右上按钮随时切换引导，到另一撤离点也会自动识别。附近可见敌人会阻止撤离；离开区域重置计时。成功后有 4.2 秒第一人称登车 / 登机离场过程，车轮和旋翼实际转动；死亡或成功进入结算，可重新开始。SMG 可在暂停菜单切换全自动 / 两连发，手枪为半自动。敌人掉落有限弹药补给。

## 移动与 AI

`pathfinding.js` 使用原 `nav.step` 验证直线段、楼梯和连廊。楼层内用缓存网格路径，楼层之间用真实门洞、坡面和楼梯连接。目标引导只能跳到经实际碰撞验证可达的后续点，避免只凭距离跳过楼梯入口。

左侧冲刺改为点击开关，再推摇杆即可持续跑动，不需要额外按住一根手指。冲刺速度 6.8m/s，有耐力消耗和恢复；真实模型有明显的低持枪倾斜、双手步态摆动，恢复瞄准时回正。跳跃按钮支持移动中起跳，重力、约 0.8m 腾空、顶板限制及落地回弹；水平方向仍使用原碰撞，不允许越过墙体、深井或栏杆。

回声支持跟随、守点、掩护与倒地救援。附近回声会在同一轿厢实际乘梯，留在外面的队友沿真实楼梯追赶。敌人分侦察兵、突击兵、装甲守卫：不同视野角、速度、装甲、反应、连发节奏和弹匣；具有巡逻、听枪声 / 奔跑声追查、记忆最后位置、移向掩体 / 侧向移动、装填的状态。射击之前重复检查视线。不同导航楼层之间采取保守遮挡规则，不会隔着楼板开火。当前为本地 PvE 小样，没有多人服务器、排位系统或完整战利品经济。

## 手机输入与资源

封面保持二维，进入模式时动态 import 场景。FPS 模块再按需载入枪械 GLB，使用同一个 WebGLRenderer 的独立相机最后渲染手臂和枪。暂停菜单可调节控制布局和手感；横竖屏位置独立保存。暂停、后台和失焦会释放移动/开火状态。

地图使用流畅画质与 30 fps 上限；FPS 不建立导览人群、车辆、标签及动线。原套房按层缓存和共享材质继续使用。射线、示踪线对象重用；枪械顺序加载，纹理下采样和重复手部材质共享。

住宅 01/02/03 模型数据恢复到完整探索模式，FPS 不请求这些模型。首次下载和 GPU 解码仍需一定时间，启动页会显示阶段进度。真实 iPhone 的设备性能需另做实测；浏览器模拟结果不应写成实体设备帧率。

## 可选模型 API

默认本地 AI 即可完成整局游戏，常见中文/英文指令先本地解析。未识别的自然语言可提交 `POST /.netlify/functions/squad-order`，请求体为 `{ "text": "队友指令" }`。

若站点所有者以后启用模型，需要在 Netlify 服务端设置：

- `FPS_MODEL_ENABLED=true`
- `FPS_MODEL_BASE_URL`：兼容 Chat Completions 的 HTTPS 基础地址，通常以 `/v1/` 结束。
- `FPS_MODEL_NAME`：模型名称。
- `FPS_MODEL_API_KEY`：只放在服务端环境变量。

服务端仅允许输出 `follow`、`hold`、`cover`，不把输出作为代码执行；输入最多 160 字，服务端超时 5 秒。缺少配置返回 503，客户端继续使用三个本地指令。模型不决定命中、伤害、弹药、位置、任务完成或胜负，API Key 不进入静态包。当前交付不要求用户提供密钥。
