# 西门、云谷艺术广场及云环路口修复

日期：2026-10-31。正式入口：[云澜汇 Netlify](https://yunlan-mall-calvin.netlify.app/)，site ID `3af33d60-6f93-4be3-a2e2-06f122ed5fc3`。

## 改动

- 喷泉西侧新增石材西门、5.6m 宽铺装步道及西外环斑马线，沿喷泉旁步道接入一期主楼的真实门厅。门洞宽 5.5m；原 `P1-1F-NWR4` 商铺缩短后保留品牌、编号和 3.5m 门面，商铺数量不变。西门两侧立柱纳入碰撞，原来与门柱重叠的一棵树移到门侧。
- 地铁 A 口左侧下沉庭院扩为约 990m² 的“云谷艺术广场”，面积超过原来两倍。6.4m 宽台阶、三层弧形木石座席、双环艺术雕塑、青铜/青绿地面嵌线、开放棚架舞台和花池按真实边界布置。围栏只在地面台阶处断开。
- 保留北侧 B1M 美食广场连接，新增 5.2m 宽地铁通廊，接入 A 通道侧墙，并避开 A 口楼梯/扶梯下端。站厅墙面和广告均切开实际门洞；邻接可见性同步登记。通廊与广场的家具碰撞模型同源。
- 云环天桥下的“滑滑梯”来自二期游乐城堡。`BatchSet.frame` 采用绝对变换，嵌套滑梯变换曾覆盖乐园的平移/旋转，使滑梯出现在世界原点。现在仅在该局部模型叠加父变换，完整滑梯恢复到 `(34,-140)` 的游乐区，不改变全局变换语义或桥梯位置。
- 保留上版一期室外地砖、34 个商业层设计地毯、浅石色屋面、玻璃光穹、停车入口与玻璃导航。新公共空间仅用于完整导览；FPS 仍使用原紧凑布局。
