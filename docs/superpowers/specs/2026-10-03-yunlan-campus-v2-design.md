# 云澜汇园区 v2：三期不规则商场 + 环形天桥 — 设计规格

日期：2026-10-03
状态：设计已获用户批准（一期重做、二期折线新月形、三期开放街区、路口环形天桥）
前置版本：`docs/superpowers/specs/2026-10-03-yunlan-mall-3d-design.md`（单栋方形商场，已合并到 main）

## 1. 目标

用户反馈："布局太规整"，希望预建二、三期，规模更大、形状不必方正，用天桥跨马路连接。

成功标准：
1. 一、二、三期外形都不是方盒子：一期 Y 形三翼 + 圆厅；二期三翼 + 两圆厅的折线新月形；三期 11 栋角度各异的低层街区建筑。
2. 原有规则继续成立，并推广到每一期：铺位不重叠且临走道、每层卫生间、客梯覆盖、扶梯 30° 且落点在楼板上、入口 ≥4、车库进出分离、楼梯疏散距离、店名唯一。
3. 环形天桥在 2F 标高（+6.5m）连通一期、二期、三期与公园，桥下净空 ≥ 5.0m。
4. 全园区任一人行入口出发都能走到任一铺位（可走天桥，也可走地面斑马线）。
5. 园区视角保持流畅：只显示各期外观；选中某一期才显示其室内。

## 3. 建筑体系：翼楼 + 圆厅

一、二期的室内商场由**圆厅**和**翼楼**组成。

- **圆厅**：圆心 C、外墙半径 R。中心放"中庭套件"（沿用 v1 已验证的中庭）：2F 以上圆角矩形洞口 34m×20m（圆角 4m）；1F→2F 扶梯两对位于洞口内；2F→3F 扶梯两对位于洞口南北两侧的独立洞口；两部观光梯位于洞口两端。套件可绕圆心旋转。圆厅不设普通铺位。
- **翼楼**：一段直线商业街，局部坐标 u 沿轴线（自圆心向外）、v 垂直轴线（u 方向转 +90°）。商业街 v∈[−7,7]，两侧店铺带 v∈[7,23]、[−23,−7]（进深 16m）。翼楼矩形从 u_a=√(R²−23²) 开始，使翼楼角点正好落在圆周上，外轮廓 = 圆周弧段 + 各翼楼矩形，翼楼之间露出弧形玻璃幕墙。
- **铺位**：店铺带从 u=R+1 开始，宽度 6–16m 错落；靠圆厅的首个铺位另开一面朝圆厅的门面。铺位在翼楼局部坐标下是矩形，世界坐标下是旋转矩形。
- **翼楼末端 6m** 为端部区：两角各一部楼梯（6×6m），中间为入口大堂 / 休息区 / 后勤走道 / 车库坡道口（视楼层而定）。
- **核心筒**（每翼一组，16×16m，位于某一侧店铺带）：2 部客梯（门朝商业街）、通往楼梯的电梯厅、楼梯（贴外墙）、卫生间（含男、女、无障碍、母婴室）。停车层只保留电梯井和楼梯，不挡车道。
- **商业街通高缝**：2F 以上商业街中线开 5m 宽洞口，分段，段间留连桥；扶梯所在位置不开。
- **地下车库（每翼）**：横断面为 外墙车位 5 | 车道 6 | 车位 5 | 中央步行脊 14 | 车位 5 | 车道 6 | 外墙车位 5（合计 46m）；圆厅下为环形车道；翼楼端部为横向车道。
- **入口**：翼楼末端立面、圆厅外露的弧形立面均可开人行入口；每栋室内商场 ≥4 个入口、朝向 ≥3 个方向。

## 4. 一期 · 云澜汇（Y 形，重做）

- 圆厅 C1=(−106,−106)，R=34，套件旋转 45°（中庭长轴指向路口）。
- 三翼：东南翼 45°，u 到 84（末端对路口，距原点 65.9m）；西翼 165°，u 到 96；北翼 285°，u 到 88。相邻翼楼间露出 34.9° 的弧形幕墙。
- 楼层：B2 −12.0、B1 −8.4、B1M −4.5、1F 0（层高 6.5）、2F 6.5、3F 12、RF 17.5。主题沿用 v1：1F 国际精品、2F 潮流服饰、3F 亲子餐饮影城（影城在西翼端部）、B1M 美食广场、RF 天台花园。
- B1M：圆厅为美食广场用餐区；西翼为云澜老街；北翼为鲜集超市（主力店）；东南翼为美食档口和餐厅。
- 扶梯 8 对：套件内 B1M↔1F、1F↔2F、2F↔3F 各两对；西翼 B1→B1M 一对（B1M 楼板开洞）；西翼 3F→RF 一对（屋面玻璃亭）。
- 入口 5 个：东南翼末端主入口（2F 同位置接天桥）、西翼末端西门、圆厅 105° 南门、345° 东门、225° 北门。北翼末端为卸货区和车库坡道口。
- 车库 B1/B2：北翼末端外两条直坡道（入、出分车道，15%）接北外环；圆厅中央为 B1↔B2 上下行直坡道，四周为环形车道；西翼中央步行脊设扶梯厅。
- 天台：圆厅玻璃穹顶；东南翼 4 家餐吧 + 卫生间 + 末端玻璃悬挑观景台 + 「云澜汇」立体字；西翼花园（草坪、儿童乐园、天空之镜、花架、花艺拱门、扶梯玻璃亭）；北翼摩天轮「云澜之眼」、IP「云宝」、设备区。

## 5. 二期 · 星湾（三翼两圆厅，更大）

- 圆厅 A=(106.07,−106.07)，B=(210.07,−106.07)，R=30。西翼自 A 以 135° 伸出，u 到 86（末端距原点 64m，对路口）；中翼连接 A、B（0°，长 104m）；东翼自 B 以 45° 伸出，u 到 72。凹面朝南围出「星湾广场」。
- 楼层：B1 −4.2（停车）、1F 0（层高 6.5）、2F 6.5、3F 12、4F 17.5、RF 23。主题：1F 国潮旗舰 + 新能源汽车展厅（中翼南侧整条店铺带）；2F 运动户外；3F 亲子教育 + 科技潮玩；4F 餐饮 + IMAX 影城（东翼端部）；RF 天空跑道 + 篮球场 + 屋顶花园。
- 圆厅 A 用标准套件（1F→2F、2F→3F 各两对，观光梯两部）；圆厅 B 为真冰场（1F 中央冰面 28×16m，2F 以上为冰场上方洞口），1F→2F 扶梯两对在洞口南北两侧的独立洞口；3F↔4F 扶梯两对分别在中翼、东翼商业街。每两层之间 ≥2 对。
- 入口 5 个：西翼末端主入口（2F 接天桥）、东翼末端、圆厅 A 南侧弧面、圆厅 B 南侧弧面、圆厅 A 北侧弧面。
- B1 停车：中翼北墙外两条直坡道向北接星湾北街。
- 品牌：原创中英文店名，按业态从词库取用，全园区唯一。

## 7. 中央公园与地铁站

不规则湖面、草坪、树林、环湖步道；地铁站出入口（玻璃雨棚 + 下行楼梯）在 (60,48) 附近；不设商业铺位。

## 8. 天桥

- **云环**：圆心 (0,0)，中线半径 34m、宽 6m，桥面标高 6.5（与一、二期 2F 同高），结构厚 1.0m，桥下净空 5.5m。支柱在四个街角（45°、135°、225°、315°）和大道隔离带（0°、180°）。玻璃顶棚 + 夜间灯带。
- **四条连廊**（宽 5m，沿对角线）：225° → 一期东南翼末端 2F；315° → 二期西翼末端 2F；135° → 三期入口广场落地塔 (−40,40)；45° → 公园落地塔 (40,40)。落地塔含楼梯、扶梯、电梯。
- 地面斑马线保留，两种过街方式都计入连通性。

## 9. 交互与性能

- 界面层级：园区 / 一期 / 二期 / 三期 → 楼层。目录与搜索覆盖全园区。
- 渲染分级：园区视角每层只显示外立面和楼板（屋面层显示完整内容）；选中某一期显示该期全部室内；选中楼层时剖切显示（上层隐藏）；爆炸视图作用于当前选中的那一期。
- 阴影相机跟随视角：园区视角覆盖整个园区，单期 / 单层视角收窄以保持清晰。
- 动线、标注、昼夜、拾取高亮沿用 v1。
- 一键导览：一期主入口 → 圆厅中庭 → 扶梯上 2F → 经云环天桥 → 二期冰场圆厅 → 天空跑道 → 俯瞰三期街区 → 一期天台摩天轮 → 园区全景。

## 10. 布局模型与测试

数据契约（相对 v1 的变化）：
- 新增 `buildings`；每个楼层带 `building` 字段，楼层 id 形如 `P1-1F`。
- 铺位和用房带局部坐标系 `frame`，`rects`/`fronts` 为局部轴对齐矩形和带朝向的门面（沿用 v1 写法）；同时给出世界坐标 `polys`（凸多边形）和 `wfronts`（带外法线 nx,nz 的线段）供测试与拾取。
- 走道 `walk[].poly`、洞口 `voids[].poly` 为世界坐标多边形；楼板为 `slab.pieces[{outer, holes}]`。
- 电梯带局部坐标与门的外法线；坡道车道为多边形。
- 新增 `site.walk`（人行道、斑马线、广场、公园）、`bridges`（桥面、连廊、落地塔及其上下连接）。

测试（node:test，先写测试；按期分文件）：
1. 各期楼层与标高符合本规格；同一期内各层主题不同。
2. 铺位数量：一期 1F/2F ≥25、3F/B1M ≥20；二期 1F–4F 每层 ≥20；三期合计 ≥40。
3. 同层铺位与用房互不重叠，都在楼板内，不落入洞口。
4. 每个铺位至少一段门面外侧探测点落在走道内。
5. 卫生间：一期 B1M 与 1F–3F 每层 ≥2 组、B1/B2/RF ≥1 组；二期 1F–4F 每层 ≥2 组、B1/RF ≥1 组；三期 ≥2 组；门口通走道。
6. 客梯覆盖各期每一层（每层 ≥2 部），门口探测点在走道内；一、二期各有 2 部观光梯。
7. 扶梯 30°；两端落点在楼板走道上；斜段在上层洞口内；同层扶梯互不重叠。
8. 扶梯覆盖：一期 B1→B1M、B1M↔1F、1F↔2F、2F↔3F、3F→RF 都有上下行，共 8 对；二期 1F↔2F、2F↔3F、3F↔4F 各 ≥2 对。
9. 一、二期各 ≥4 个人行入口、朝向 ≥3 个方向、恰有 1 个主入口；入口内侧是走道，外侧在楼外的广场上。
10. 车库：每个有停车层的期都有入口和出口坡道且车道不重叠；坡度 ≤15%；地面端接车道，地下端接车道；一期 B1↔B2 双向。
11. 疏散：每层 ≥2 部楼梯；室内走道到最近楼梯或出口 ≤45m（商业）/ ≤60m（停车）。
12. 停车：车位不压车道和用房；一期 B1/B2 各 ≥150、二期 B1 ≥150、三期 B1 ≥200；一期 B1 有充电位和无障碍位。
13. 天台：一期 ≥3 家餐吧、摩天轮、IP、天空之镜、观景台、立体字；二期有天空跑道和篮球场。
14. 全园区中英文店名唯一，铺位号唯一。
15. 天桥：桥面 6.5m、净空 ≥5.0m；连廊落在一、二期 2F 走道或落地塔上；支柱不压车行道；建筑不压道路与人行道，各期互不重叠。
16. 全园区连通：所有入口、走道、桥面、铺位处于同一步行网络。
