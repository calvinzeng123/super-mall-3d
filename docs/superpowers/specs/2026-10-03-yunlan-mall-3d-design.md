# 云澜汇 YUNLAN MALL 3D 商场场景 — 设计规格

日期：2026-10-03
状态：已获用户批准（含天台补充：餐吧 + 网红打卡点）

## 1. 目标

在浏览器里呈现一个写实风格、可交互的 3D 超级购物中心：

- 3 层商业（1F–3F）+ B1M 夹层美食广场 + B1/B2 地下车库 + RF 天台花园，共 7 个楼层。
- 每个商户都有招牌贴图；每层的布局、动线合理，场景主题各不相同。
- 有手扶梯、电梯、每层卫生间、车库出入口、≥4 个人行入口。
- 天台有多家餐吧和网红打卡点（摩天轮、原创 IP 雕塑等）。

成功标准：
1. 自动化布局测试全部通过（见第 8 节）。
2. 浏览器中逐层截图检查：每层可见商铺招牌、扶梯、电梯、卫生间；全楼视角可见 4 个入口、车库出入口、天台摩天轮和 IP。
3. 普通笔记本上能流畅交互（目标 ≥ 45 fps），低帧率时自动降级。

## 2. 方案

方案 A：Three.js 网页 + 程序化建模。所有几何都按"布局数据"生成，招牌贴图由 Canvas 绘制，最终打包成单个 HTML（three.js 从 jsDelivr CDN 加载），并发布为在线 Artifact 链接。

|---|---|---|---|
| RF | +16.5 | — | 天台花园、餐吧、摩天轮、IP 打卡点 |
| 3F | +11.0 | 5.5 | 亲子 · 餐饮 · 影城 |
| 2F | +5.5 | 5.5 | 潮流服饰 · 运动 |
| 1F | ±0.0 | 5.5 | 国际精品 · 美妆，4 个人行入口 |

坐标系：x 向东为正，z 向南为正，y 向上；建筑 x∈[−60,60]，z∈[−40,40]（120m × 80m）。

## 4. 平面布局（1F–3F 共用骨架）

- 外圈店铺带（进深 16m）：北带 z∈[−40,−24]、南带 z∈[24,40]、西带 x∈[−60,−44]、东带 x∈[44,60]。四角为主力店，向环廊开门。
- 环形走廊（6m）+ 4 个岛铺（NW/SW/NE/SE，各 15m × 12m，每个分 2 铺）。
- 主中庭：2F/3F 洞口 x∈[−17,17]、z∈[−10,10]（圆角 4m）；1F 洞口 x∈[−5,5]、z∈[−8,8]，向下贯通 B1M 美食广场；屋顶为玻璃天窗。
- 主动线 = 环形走廊 + 南北/东西十字轴线，十字轴把 4 个入口直接连到中庭，无死胡同。
- 东西两端在 2F/3F 为观景休息区，连接消防楼梯。

### 核心筒与辅助用房（各层对齐）
- 西客梯核 Core W：x∈[−36,−28]、z∈[−40,−24]，3 台客梯，B2–RF。
- 西卫生间 WC W：x∈[−28,−20]、z∈[−40,−24]。
- 服务核（货梯 + 楼梯）：x∈[12,20]、z∈[−40,−24]，B1M–RF（停车层不设）。
- 东客梯核 Core E：x∈[28,36]、z∈[24,40]，3 台客梯，B2–RF。
- 东卫生间 WC E：x∈[20,28]、z∈[24,40]。
- 消防楼梯：Core W、Core E、服务核各 1 部；S4 x∈[−60,−55]、z∈[−10,−4]（B2–RF）；S5 x∈[55,60]、z∈[4,10]（1F–RF）。

### 入口与出入口
- 人行入口（1F）：南门主入口 x∈[−8,8]（16m 宽，雨棚 + 旋转门 + 服务台）、北门 x∈[−4,4]、西门 z∈[−4,4]、东门 z∈[−4,4]。
- 车库：入口坡道在西北（由街面向东下行至 B1），出口坡道在东北（由 B1 向东上行至街面），坡度 15%；两条坡道在 x∈[−6,6] 的连接区与车库中轴相接，进出车辆均为右转，不交叉（相对设计稿的东西位置做了对调，原因即在此）。
- B1↔B2：一对单向坡道（下行北侧车道、上行南侧车道），位于东北角 x∈[25,49]、z∈[−39.5,−30.5]。
- 卸货区：北侧服务核外，货车停在坡道顶板平台上，与顾客动线分离。

## 5. 各层场景

- **RF 天台花园**：草坪、乔木、花境、木栈道、花架长廊、儿童游乐区、中庭玻璃天窗、设备区格栅围挡。
  - 餐吧 4 家（玻璃亭 + 外摆 + 夜间串灯）：云端精酿 SKY BREW、落日小酒馆 SUNSET BAR、星空西餐 STARLIGHT BISTRO、炭火烤肉 EMBER GRILL。
  - 网红打卡点：天台摩天轮"云澜之眼"（直径 30m，轮面朝南，夜间灯光）、原创 IP"云宝"巨型雕塑（天台 + 南广场各一）、天空之镜水景、玻璃悬挑观景台、"云澜汇"立体字、花艺拱门。
- **3F 亲子 · 餐饮 · 影城**：影城（东北 L 形大铺）、儿童乐园（西北）、书店（西南 L 形）、电玩城（东南）、主题餐厅；暖木色地面；3F→天台扶梯在西侧通道，屋面设玻璃亭。
- **2F 潮流服饰 · 运动**：男女装、运动户外、鞋包、潮玩；浅灰水磨石 + 冷色点缀；中庭周边快闪展台。
- **1F 国际精品 · 美妆**：白色大理石 + 香槟金收边；珠宝腕表、美妆香氛、旗舰店、咖啡；南门大堂服务台；中庭悬挂艺术装置。
- **B1M 美食广场**：中庭下方用餐区；四周美食档口；西翼"云澜老街"（灯笼、木门脸、牌坊）；东翼精品超市；北侧有从 B1 停车场上来的扶梯厅。
- **B1 / B2 停车场**：B1 蓝色分区、B2 绿色分区，柱上分区编号；新能源充电位、无障碍车位；单向推荐环线 + 地面箭头；人行斑马线直达电梯厅；周边设备房。

## 6. 垂直交通

| 区段 | 位置 | 数量 |
|---|---|---|
| B1→B1M | 北侧扶梯厅 x≈−16，B1 底部 z≈−31 向南上行 | 1 对 |
| B1M→1F | 1F 洞口内，西道向北上行、东道向南上行 | 2 对 |
| 1F→2F | 2F 洞口内，西侧 x≈−10.6 向北、东侧 x≈10.6 向南 | 2 对 |
| 2F→3F | 3F 楼板独立洞口，中庭北侧向东、南侧向西 | 2 对 |
| 3F→RF | 西侧通道 z≈0 向西上行，屋面玻璃亭 | 1 对 |

扶梯坡度 30°，水平投影 = 层高 / tan30°。共 8 对 16 部。

电梯：Core W、Core E 各 3 台客梯（B2–RF）；中庭观光电梯 2 部（x=±15.5, z=0，B1M–3F）；货梯 1 部（服务核）。

## 7. 交互

- 鼠标旋转/缩放全景；楼层栏点选 → 只显示该层及以下；爆炸视图。
- 店铺目录 + 搜索，点击飞到店门口并高亮；悬停提示店名、业态、铺位号。
- 动线开关：人流（青）、车流（橙）、货流（紫）流动箭头；行人与车辆动画。
- 昼夜切换（夜景招牌、橱窗、路灯、摩天轮发光 + 泛光后期）。
- 一键导览：南门 → 中庭 → 扶梯逐层 → 天台摩天轮。
- 不做：第一人称键盘自由行走。

## 8. 技术结构与验证

```
super-mall-3d/
  src/layout/   纯数据：楼层、铺位、洞口、扶梯、电梯、卫生间、楼梯、入口、坡道、车位、天台要素、品牌表
  src/render/   Three.js：材质贴图、几何合并器、各类构建器、动画、交互、UI
  tests/        node:test 布局规则测试
  build.mjs     esbuild 打包 → dist/mall.html（完整页面）+ dist/artifact.html（发布用片段）
```

布局测试（TDD，先写测试）：
1. 同层铺位、核心筒、卫生间、楼梯互不重叠，且不落入洞口。
2. 每个铺位至少有一段门面临公共走廊。
3. B1M、1F–3F 每层 ≥2 组卫生间；B1、B2、RF 各 ≥1 组。
4. 每层都有客梯停靠；客梯覆盖 B2–RF。
5. 扶梯：坡度 30°（±1%）；底部落点在下层楼板、顶部落点在上层楼板；斜段投影位于上层洞口内；B1→B1M→1F→2F→3F→RF 每段都有上下行。
6. 1F 人行入口 ≥4 且分布在 4 个方向；车库入口、出口各 1 且分离；地面坡道坡度 ≤15%；B1↔B2 双向可达。
7. 连通性：从每个人行入口、每个停车层电梯厅出发，都能走到每一个铺位。
8. 楼梯：每层 ≥2 部，走廊任一点到最近楼梯直线距离 ≤ 45m。
9. 天台：餐吧 ≥3、摩天轮 1、IP 雕塑 ≥1。
10. 店名唯一，全部为原创虚构品牌。

出错处理：WebGL 不可用 / CDN 加载失败显示提示；帧率持续低于 30 时关闭阴影与泛光。

交付：源码、`dist/mall.html`（可双击打开）、在线 Artifact 链接；交付前浏览器逐层截图检查。
