# 云澜汇园区 v3：一期第四翼 + 方庭（原四方格商场）+ 地铁云澜汇站 — 设计规格

日期：2026-10-04　基于：v2 规格（2026-10-03-yunlan-campus-v2-design.md），坐标约定不变（x 向东、z 向南、角度从 +x 转向 +z）。

## 1. 目标

1. 一期西北空地放回 v1 的"原四方格商场"（下称**方庭**），原尺寸 120×80m，楼层与一期完全对齐，作为一期的延展。
2. 方庭与一期之间不是窄连廊，而是一条**全宽商业翼（西北翼，第四翼）**：两侧店铺 + 中间商业街，1F–3F 室内连通，地下车库连通。
3. 地铁站扩建为**站厅 + 站台（含列车）+ 四条对角线地下通道**：分别直通一期 B1M、二期 B1、三期 B1 与公园；四个街区各有一个地面出入口（A/B/C/D）。
4. 已有一、二、三期、云环天桥、公园全部保留；全部规则测试继续通过。

## 2. 一期第四翼（西北翼 NW）

- 翼楼 frame：原点圆厅圆心 C=(−106,−106)，角度 225°（u 指向西北），v=u 转 +90°（+v 指向北翼一侧，−v 指向西翼一侧）。
- 与西翼（165°）、北翼（285°）各成 60°，靠近圆厅处三翼会相交：西北翼两条长边（v=±23）与西翼北边、北翼西边相交于 u=39.85。
  - **全宽段**：u∈[39.85, 99.37]，|v|≤23（与其他翼同宽）。
  - **喇叭口**：圆厅弧（225°±17.4°，即西翼、北翼外墙与圆周交点之间）到 u=39.85 的梯形区域，并入室内。
- 末端 u=99.37 正好是方庭东南斜面（见第 3 节），两者无缝相接，不设端墙、端部楼梯和入口。
- 商业层（B1M、1F、2F、3F）：商业街 v∈[−7,7]（u 自 29 到 99.37）；两侧店铺带 v∈[7,23]、[−23,−7]，u 自 39.85 起按宽度序列切铺；喇叭口两侧为口袋走道（多边形）；末端两家店各开一面朝方庭大厅的门面。
  - 核心筒（2 客梯 + 楼梯 + 卫生间）在 −v 带 u∈[62,78]。
  - 2F/3F 商业街开通高缝；扶梯两对：1F→2F、2F→3F（编号 K7、K8）。
- 停车层（B1、B2）：车道 v∈±[12,18]、步行脊 |v|≤7（脊自圆厅环道起），车位排从 u=41 起；分区 J。
- 天台：西北翼屋面为木平台，商业街缝上方天窗，少量乔木。

## 3. 方庭（原四方格商场）

- 局部 frame：F_SQ = frame(−220,−200,0)，局部坐标即 v1 坐标；外轮廓 x∈[−60,60]、z∈[−40,40]（世界 x∈[−280,−160]、z∈[−240,−160]）。
- **东南斜面**：局部直线 x+z=67.47，端点 (27.47,40)、(60,7.47)，宽 46m，与西北翼末端重合。
- 楼层：与一期共用 B2 −12、B1 −8.4、B1M −4.5、1F 0（层高 6.5）、2F 6.5、3F 12、RF 17.5；方庭的铺位、用房、走道直接属于一期对应楼层。
- 平面沿用 v1：外圈店铺带进深 16m（北 z∈[−40,−24]、南 z∈[24,40]、西 x∈[−60,−44]、东 x∈[44,60]）、6m 环廊、4 组岛铺、中央中庭（1F 洞口 x∈[−5,5]×z∈[−8,8] 通 B1M；2F/3F 洞口 x∈[−17,17]×z∈[−10,10] 圆角 4m）、十字轴线。
- 斜面带来的改动：
  - 取消 v1 的 S6、SE、E2、E3 铺位与 3F 电玩城；电玩城改到东南岛铺（合并为一铺）；B1M 精品超市收窄到 x∈[23,49]。
  - 东客梯核移到南带 x∈[8,16]，东卫生间移到 x∈[16,24]；楼梯 S5 移到东带 x∈[55,60]×z∈[−10,−4]。
  - 原东南角改为**入口大厅**：局部多边形 (24,24)-(24,40)-(27.47,40)-(60,7.47)-(60,4)-(44,4)-(44,24)，连接西北翼商业街与环廊、东门。
- 垂直交通（v1 位置，按新层高重算斜段）：扶梯 8 对（B1→B1M 1、B1M↔1F 2、1F↔2F 2、2F↔3F 2、3F→RF 1，编号 SQ-P0…SQ-P7）；中庭观光梯 2 部（B1M–3F）；客梯核 2 个各 3 台（B2–RF）；服务核货梯 + 楼梯；楼梯 5 部。
- 人行入口（1F）：南门 x∈[−8,8]、北门 x∈[−4,4]、西门 z∈[−4,4]、东门 z∈[−4,4]，均非主入口（一期主入口仍为东南主入口）；一期广场扩到整块地块，四门外侧均为场地步行区。
- 车库：方庭 B1/B2 车位排布沿用 v1，经西北翼车道与一期车库连成一体，进出共用一期北翼坡道；分区 K。
- 天台（RF）：中庭玻璃拱顶天窗；东半部**露天星空影院**（银幕 + 阶梯躺椅）；西半部**屋顶农场**（种植池 + 玻璃温室）；北侧观景平台；3F→RF 扶梯玻璃亭；天台卫生间。
- 外轮廓：一期外轮廓 = 圆厅 + 四翼（相邻两翼内侧边在圆外相交时直接相接，不走圆弧）+ 方庭（在西北翼末端拼接，去掉斜面这条内边）。

## 4. 地铁 云澜汇站（新"楼栋" M）

- 楼栋 id M，名称"地铁 · 云澜汇站"，kind `metro`；两层：
  - **M-B1 站厅**：标高 −4.5（与一期 B1M、三期 B1 同高），层高 4.0。
  - **M-B2 站台**：标高 −12，层高 5.5。
- 站厅：路口地下 x∈[−66,66]、z∈[−11,11]；付费区 x∈[−36,36]（两端闸机阵列），非付费区设售票机、客服中心、便利店与面包店（2 个铺位）、卫生间；2 部客梯（站厅↔站台）。
- 站台：岛式站台 x∈[−60,60]、z∈[−6,6]，两侧轨道沿 x 向，屏蔽门；6 节编组列车（114m）定时进站、开门、出站。
- 站厅↔站台：扶梯 2 对（上下行，斜段在站厅楼板洞口内）+ 楼梯 2 部 + 客梯 2 部。
- 四条地下通道（属于 M-B1，宽 8m，沿对角线 frame(0,0,θ) 的 u 向，自 u=13 起）：
  - 225° → 一期 B1M 东南翼末端（u≈65.9）；
  - 315° → 二期 B1 西翼末端（u≈64）；
  - 135° → 三期 B1 东北角 (−40,40)（u≈56.6）；
  - 45° → 公园 B 口（u≈75，B 口移到 (53,53)）。
- 地面出入口：A（一期广场）、B（公园）、C（二期广场）、D（三期街区）；每口为玻璃雨棚 + 楼梯 + 上行扶梯，自通道升到地面（升高 4.5m）；A/C/D 由通道侧向分支接出。
- 跨楼连接：用"入口"表示——`entrance.to` 可以是另一栋的楼层 id（如一期 B1M 的地铁口 `to: 'M-B1'`），步行连通图按该楼层的走道连接。

## 5. 界面与渲染

- 分期按钮：园区 / 一期 / 二期 / 三期 / 地铁。方庭与西北翼属于一期（楼层按钮不变）。
- 西北翼、方庭沿用现有渲染（外立面按外轮廓生成、店面、室内、用房、扶梯、观光梯、车库）；补充：方庭中庭艺术装置与服务台、天台影院与农场、方庭动线。
- 地铁：站厅（浅色水磨石、吊顶灯带、柱子、闸机、售票机、导向牌"云澜汇站"）、通道（墙砖、灯带、广告灯箱）、站台（屏蔽门、轨道、列车动画）、地面出入口（雨棚 + 楼梯 + 扶梯）、各期 B1/B1M 的"地铁 Metro"连通口标识。
- 导览：在"二期天台"与"俯瞰三期"之间加入"地铁站厅 · 站台列车"两步，并加入"一期方庭中庭"一步；园区全景仍为结尾。
