# 第一人称漫游（v4）设计

> 状态：已与用户确认（2026-10-05）。形式：同页面加「漫游」模式；移动：步行碰撞 + 可切换飞行；碰撞用布局数据（方案 A）。

## 1. 目标

在现有园区页面里加一个第一人称漫游模式，像《我的世界》创造模式一样：以人眼高度在园区里走动，走进每一栋楼、每一层、每一家店、地铁站、天桥和天台；随时可以飞起来穿墙、靠近任何细节看。横屏、竖屏的手机和电脑都能玩。**建筑本身不改动。**

## 2. 交互

### 2.1 进入与退出

- 工具栏加「漫游」按钮。点击后关闭俯瞰相机，进入第一人称；「退出」回到进入前的俯瞰视角（楼栋、楼层选择不变）。
- 出生点：
  - 聚焦了某层：该层上离走道中心最近的可站立点，面朝走道方向；
  - 只选中了某一期：该期 1F 主入口内侧 2m（地铁：站厅中部）；
  - 园区总览：一期东南主入口外的广场，面朝入口。
- 导览进行中点「漫游」先停止导览。

### 2.2 操作

| | 电脑 | 手机（横竖屏） |
|---|---|---|
| 转视角 | 点画面锁定鼠标后移动鼠标（Esc 释放） | 右侧（屏幕宽度 40% 以右）拖动 |
| 走 / 跑 | WASD 或方向键；按住 Shift 跑 | 左下摇杆；推过 80% 为跑 |
| 跳 / 上升 | 空格（飞行时上升） | ▲ 按钮 |
| 下降（飞行） | C 或 Ctrl | ▼ 按钮（只在飞行时显示） |
| 切换飞行 | 连按两下空格，或 F | 「飞」按钮 |
| 互动（楼梯 / 电梯） | E 打开选项，数字键 1–9 或点击选择 | 「互动」按钮（靠近时出现） |
| 传送 | 「地点」按钮打开目录 | 同左 |
| 退出漫游 | 「退出」按钮 | 同左 |

漫游时隐藏工具条、分期与楼层栏、目录、图例和提示（避免误触，沿用手机端修复的经验）。

### 2.3 屏幕信息（HUD）

- 顶部：当前位置（"一期 · 1F 国际精品"、"三期 · 1F 街巷"、"云环天桥"、"地铁 · B1 站厅"、"室外 · 中央公园"），右侧「地点」「退出」。
- 中央准星；准星对准 25m 内的铺位或设施时，下方显示名称卡（店名、业态、铺位号 / 设施说明），沿用现有拾取信息。
- 靠近楼梯或电梯门口时弹出互动面板：楼梯给出相邻楼层（"上楼 · 2F""下楼 · B1M"），电梯列出全部停靠层。
- 电脑首次进入时显示操作提示，点击画面后淡出。

## 3. 导航模型（`src/layout/nav.js`，纯函数，可在 Node 中测试）

`buildNav(layout)` 生成：

### 3.1 楼面（floor）

- 每个楼层一个楼面，`y = lv.elev`。
- `ground`：室外地面，`y = 0`；可站立区 = 园区范围（x、z ∈ [−298, 298]）挖掉一期、二期外轮廓、三期街区矩形、湖面、坡道敞开段、地铁梯井。
- 三期 1F 街巷就是三期街区内的地面：`ground` 与 `P3-1F` 沿街区矩形四条边互为传送边（同高，无缝切换）。
- `bridge`：云环天桥桥面，`y = 6.5`；可站立区 = 天桥走道多边形（环、连廊、落地塔）。

### 3.2 可站立判定（support）

楼层的可站立区 = 楼板拼块（外框减洞）再减去洞口（中庭、扶梯洞、天窗、电梯井）。人的中心与以半径 0.3m 取的四个方向点都必须可站立，这样走到楼板边、中庭边会被挡住，不会掉下去——不需要单独建栏杆墙。

### 3.3 墙（wall）

线段，按身体半径 0.3m 做圆与线段的碰撞并沿墙滑动：

- 铺位：外轮廓减去门面上的门洞。门洞规则与渲染一致（抽到共享的 `src/layout/frontage.js`）：
  - 玻璃 / 影城 / 超市店面：门宽 = 门面长 ≥5m 时 min(3.2, 0.3·长)，3–5m 时 1.8m；超市两扇门（1/4、3/4 处），其余一扇（中点）；门面 <3m 时整段敞开；
  - 三期街巷店面：门宽 min(2.2, 0.3·长)，居中；
  - 档口、老街、天台餐吧、屋顶酒吧亭：整段敞开；
  - 冰场：四周封闭。
- 用房（楼梯间、核心筒、卫生间、设备房、客服中心等）：四周封闭（楼梯、电梯在门口互动）。
- 不在核心筒里的电梯井（观光梯、外挂梯、地铁电梯）：按井道尺寸封闭。
- 扶梯在下层的占地：两侧与上端封闭，只留下端入口。
- 地铁：闸机柜（柜间通道可过）、付费区栏杆、售票机、屏蔽门（常闭）。
- 室外：落地塔塔身。

### 3.4 传送边（portal）

人的移动线段穿过传送边时切换楼面：

- 入口（`entrance`）：`e.level` ↔ `e.to`（`site` → `ground`，`bridge` → `bridge`，楼层 id → 该楼层）。地铁地面出入口不走这里（见坡道）。
- 三期街区矩形四边：`ground` ↔ `P3-1F`。

### 3.5 坡道（slope）

带方向的矩形，长度方向上高度线性变化，两侧为墙，两端分别接上下两个楼面；在坡道上时人处于"坡道状态"：

- 扶梯（每条梯道一段，宽 1.2m 可走）：上行 / 下行带 0.5m/s 的传送速度，站着不动也会被送到另一端；
- 地铁地面出入口：楼梯 + 扶梯整段作为一段坡道（站厅层 ↔ `ground`）；
- 落地塔扶梯：`ground` ↔ `bridge`；
- 车库坡道（各期进出口）、一期圆厅下 B1↔B2 坡道。

### 3.6 互动点（link）

- 楼梯：每部楼梯在每个停靠层的门口（门段中点外 1m）；选项为相邻停靠层。
- 电梯：每部电梯在每个停靠层的门口（门外 reach + 0.6m）；选项为全部停靠层。
- 落地塔楼梯与电梯：`ground` ↔ `bridge`。
- 人站在互动点 1.6m 内时可互动；选择后黑场 0.35s，传到同一部楼梯 / 电梯在目标层的门口，面朝门外。

### 3.7 查询接口

- `step(nav, state, dx, dz, dt)`：按墙、可站立区、传送边、坡道解算一步移动，返回新状态（楼面、坐标、高度）。
- `landAt(nav, x, z, yMax)`：飞行结束时找正下方最高的可站立楼面。
- `linksNear(nav, floorId, x, z)`：附近的互动点。
- `spawn(nav, layout, { building, level })`：出生点。
- `floorLabel(nav, layout, floorId, x, z)`：位置名称。

墙与互动点按 8m 网格建空间索引；每帧只查附近格子。

## 4. 第一人称控制器（`src/render/explore.js`）

- 状态：楼面、x、z、脚下高度、yaw、pitch、是否飞行、竖直速度、所在坡道。
- 视线高 1.62m；步行 2.8m/s，跑 6m/s；跳起初速 4.5m/s、重力 12m/s²（只影响视线高度）；飞行 8m/s，按住加速到 30m/s，飞行不碰撞。
- 相机高度朝目标高度做指数平滑（跨楼面的小台阶、坡道起伏不会跳）。
- 关闭飞行：`landAt` 找到下方楼面则落下（下落有动画）；找不到则保持飞行并提示"下方没有可站立的地方"。
- 阴影中心随人移动超过 20m 时更新（半径 70m）。

## 5. 显示规则（漫游时）

- 人所在的楼（由当前楼面决定）：所有楼层完整显示（室内、楼板、外立面），不剖切、不爆炸；上一层楼板就是天花板。
- 其他楼：外观模式；人在室外且离某栋楼外轮廓 30m 内时，这栋楼的室内也显示（透过玻璃能看到）。
- 地铁：人在地铁楼面或与站厅相连的地下层（一期 B1M、二期 B1、三期 B1）时显示站厅与站台。
- 场地始终显示；标注、动线隐藏；行人照常行走。
- 准星拾取：从屏幕中心发射线，候选为当前楼栋各层与场地的拾取盒，距离 ≤25m。

## 6. 界面与代码改动

- `src/shell.html`：漫游 HUD（位置条、准星、名称卡、互动面板、提示）、手机摇杆与按钮、样式（横竖屏）。
- `src/render/ui.js`：工具栏「漫游」；漫游时目录点击改为传送（分期 → 主入口，楼层 → 该层出生点，店铺 → 店门外 2m 面朝店）。
- `src/render/app.js`：`state.explore`、`applyVisibility` 漫游分支、`app.enterExplore()` / `app.exitExplore()`；漫游时停用 OrbitControls 与镜头飞行。
- `src/layout/frontage.js`：店面样式与门洞规则（渲染与导航共用）；`storefronts.js`、`street.js` 改为引用它。

## 7. 性能与内存

- 导航模型只存线段与多边形（数千条线段），不保留任何顶点数据，不影响第 8 版的内存瘦身。
- 漫游时完整显示一栋楼：一期全部楼层约 150 次绘制调用，与当前聚焦视图同量级。

## 8. 测试（`tests/nav.test.js`，先写）

1. 每个入口（不含地铁地面出入口）：从内侧 1.5m 沿法线走到外侧 1.5m，不被挡，楼面切换到正确目标。
2. 每个铺位：从门外 1.5m 朝门内走 3m，进入铺位内部（不被挡）。
3. 抽查铺位侧墙：从铺位内朝侧墙走，停在墙前 ≥0.29m。
4. 中庭：一期 2F 从中庭边朝中庭中心走，停在洞口外。
5. 扶梯：从每部上行扶梯下端入口往前走，若干秒后到达上层楼面且高度等于上层标高；下行扶梯同理到达下层。
6. 地铁出入口坡道：从站厅一侧走上去到达 `ground`。
7. 出生点（总览、各期、各层）都可站立且不与墙相交。
8. 楼梯、电梯每个停靠层的互动点都可站立。
9. 连通：一期 1F 从主入口内侧按 1m 网格在可站立且不穿墙的点上广度优先，能到达同层每家店的门口。

操作手感、显示规则在浏览器里验证（电脑与手机模拟，横竖屏截图）。
