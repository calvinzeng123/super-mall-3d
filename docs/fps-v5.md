# 封锁行动 v5 · 行动升级与操作界面

2026-10-20。分支 `feat/fps-gameplay-v5`，基于 `feat/explore-v4` 的 FPS 搜索撤离玩法继续扩展。
本轮没有新增外部下载资源：主页只有封面图，进入 FPS 后才载入原有 CC BY 4.0 枪械/手臂与 MIT 人物模型；
近战刀、手雷、护甲、情报碎片与所有新特效均由代码生成。

## 1. 新增玩法

| 系统 | 行为 | 实现位置 |
| --- | --- | --- |
| 滑铲 | 冲刺中按蹲伏（键盘 `C`）触发，速度 9 m/s 二次缓出到步行，有 1.1 s 冷却与耐力消耗；镜头压低、武器斜持 | `mobility.js`、`game.js`、`viewmodel.js` |
| 近战刀 | 2.6 m 内短刀，未察觉敌人一击无声处决（+75 分），正面命中 52 伤害；HUD 冷却环 + X 键 | `rules.js`、`game.js`、`viewmodel.js` |
| 手雷 | 2 枚起步（老兵 1 枚），抛物线投掷 1.02 s 后起爆；7 m 内按距离衰减 + 视线判定伤害，爆炸会惊动附近敌人 | `rules.js`、`game.js`、`world.js`、`effects.js` |
| 护甲 | 0–100，吸收 65% 伤害；地图上散落护甲板，精英重装被击杀额外掉落 50 | `rules.js`、`mission-layout.js`、`world.js` |
| 情报碎片 | 5 枚隐藏情报，自动拾取 +150 分并补弹；结算与 HUD 计数 | `mission-layout.js`、`game.js`、`hud.js` |
| 可选目标 | 地下连廊安防终端按住 4 s 切断监控：敌人视野 ×0.72，补 1 急救包 + 1 手雷 | `mission-layout.js`、`game.js`、`world.js` |
| 计分与连杀 | 基础 100 分，爆头/近战/无声处决加成，连杀倍率最高 ×1.75；击杀信息流、命中反馈、受击方向、低血量心跳 | `rules.js`、`game.js`、`hud.js` |
| 敌人升级 | 新增狙击手（长距离单发高伤），车库精英重装掉落护甲；敌人死亡倒地淡出、受击闪白 | `enemy-tactics.js`、`mission-layout.js`、`world.js` |
| 难度 | 行动简报表选择标准/老兵：老兵敌人伤害 +35%、命中 +18%、撤离倒计时 ×1.2、初始补给更少 | `rules.js`、`launcher.js`、`game.js` |
| 教学提示 | 首次行动、被发现、弹匣打空、低血量、撤离等上下文提示，可关闭 | `game.js`、`hud.js` |

任务路线与原版一致（一期终端 → 酒店 2F 情报 → 车辆/直升机撤离），新增内容不改变两条撤离路线的导航有效性；
`tests/fps-mission-v5.test.js` 用原 `buildNav`/`clear`/`findPath` 验证了全部新增点可走。

## 2. 动作与镜头

- 第一人称枪械新增呼吸待机、视角摆动延迟、ADS 阻尼、冲刺→停步回正、逐武器后坐力与水平摆动。
- 滑铲姿态、跳跃/落地镜身下沉、开火与受击镜头抖动（设置中可调强度）、爆炸闪光与尘土。
- 手枪空仓时套筒保持后坐锁定；SMG 保留源骨骼换弹动画，切枪先收旧枪再出新枪。
- 近战刀与手雷为程序化几何：刀身/护手/握把、投掷动作（.72 s，.52 s 出手）；随模块统一释放。
- 敌人命中闪白、死亡前倾倒地并淡出；队友倒地同样处理，救援后恢复。
- 世界特效使用固定 48 个精灵池（命中血雾/火花、爆炸、落地尘土），无逐帧分配、无外链贴图。

## 3. 首页与设置

- **封面**：重做为行动简报式主页——行动简报卡（3 个目标 + 5 项统计）、双模式卡、操作说明/素材署名弹窗、
  动画载入进度与轮换提示；FPS 入口先进入行动简报，选择标准/老兵难度后才初始化 3D。
- **HUD**：罗盘刻度带（目标/撤离/队友标记）、计时与情报计数、难度、可选目标进度、击杀信息流、
  分数/倍率/连杀、护甲条、手雷与近战按钮（带冷却环）、受击方向弧、低血量暗角、拾取提示、教学提示。
  右上得分与撤离按钮、左侧队伍/罗盘/信息流均已重排，避免 1.4 倍按钮下的遮挡。
- **设置 v2**：`yunlan.fps.settings.v2`（自动迁移 v1 布局）。五个分页：
  操作（灵敏度、预设、反转、摇杆死区、瞄准辅助）、界面（按键大小/透明度、准星样式/颜色/大小、HUD 缩放、
  信息流/罗盘/提示/受击方向/低血量开关）、显示（镜头抖动强度）、音频（主音量、音效）、辅助。
  每页可单独重置，保存有防抖与“设置已保存”反馈。
- **暂停菜单**：行动/设置/操作说明/署名四个分页，行动页显示实时用时、得分、情报、可选目标与难度，
  保留继续、重开、返回封面、队友指令与射击模式。
- **结算**：S/A/B/C/D 评级、行动得分、最高连杀、情报碎片、可选目标、难度与原有六项统计。
- **编辑器**：12 个可拖动按钮（含近战/手雷），2.5% 网格吸附、选中高亮、尺寸提示、按方向重置；
  横竖屏布局分别保存。1.4 倍按钮在 375×667、667×375、430×932、932×430 下全部不越界、互不重叠。

## 5. 已知边界

- 本轮浏览器为 Playwright + SwiftShader 软件渲染（约 2–3 fps），因此不把帧率/温升作为验收结论；
  实体 iPhone 性能仍需实机复测。滑铲、手雷、护甲与可选目标均已通过逻辑/导航测试和浏览器动作验证，
  但可选目标与屋顶撤离的完整端到端流程未在软件渲染下走完。
- 手雷为抛物线近似落点（不做墙面反弹），爆炸伤害对同层且视线可达的敌人生效。
- 近战对未察觉敌人才是处决；已交战敌人吃伤害但不会秒杀。
- 未加入联机、载具自由驾驶、武器改装或新下载模型；刀与手雷为程序化模型。
- 短横屏（高度 ≤460 px）空间不足，击杀信息流默认隐藏，改用通知/拾取提示，避免遮挡右侧动作按钮。
