# 住宅 01 / 02 三房两厅布局

2026-10-09。接续独立 03 四房样板；本轮是两套独立 Blender 样板，不代表园区 R1–R4 已替换。每套均为三卧、客厅、餐厅、两间卫浴、独立厨房，以及通长大阳台。户型数据分别在 `scripts/residential/plan_01.json` 与 `plan_02.json`，构建器是 `build_three_bedroom.py`。

## 01 与 02 的实际区别

| 位置 / 功能 | 01 横厅家庭型 | 02 镜像阅读型 |
|---|---|---|
| 主卧套间 | 西南；原套房床组保持 1:1 | 东南；同一床组镜像，尺寸保持 1:1 |
| 两间次卧 | 北西儿童房、北东成长次卧 | 北东客卧书房、北西儿童房 |
| 厨房入口 | 东侧 1.4m 移门，与餐厅相邻 | 南侧 1.2m 移门，经短厅廊到餐厅；原东侧对应墙封闭 |
| 公卫入口 | 玄关侧的 0.9m 门 | 餐厅北侧的 0.9m 门；原玄关侧墙封闭 |
| 餐桌 | 东西向六人桌 | 餐桌转为南北向，并重新定位留出东侧通路 |
| 客厅 | 两组源模型沙发构成会客区 | 保留主沙发，增加西窗下书桌、阅读椅与书柜 |
| 阳台家政 | 西侧实墙下洗烘塔与独立清洁盆 | 镜像到东侧实墙下 |

02 的墙洞、门的停放位置、餐桌和通行路径均重新定义；并非只换配色。`bed_northwest` 等内部 ID 为保持模块兼容沿用稳定名称，02 的实际方位应读取 `floor_rects` 和中文房间名。

## 家具和构建接口

`assembly` 为构建器可直接调用的结构化数据，包含 `source_bed`、`sofas`、`beds`、`wardrobes`、`studies`、`baths`、`kitchens`、`dining`、`laundry`、`balcony`，以及媒体柜、茶几、镜子、阅读区等坐标。

- 坐标是 Blender X 东、Y 北、Z 上，单位米。`origin` / `target` 已是最终世界坐标，`yaw` 为弧度。
- `mirror_x:true` 表示局部 X 反射：`T(origin) · Rz(yaw) · Scale(-1,1,1)`。02 不能再对这些世界坐标整体镜像一次。导出前应烘焙镜像矩阵并校正法线。
- 源主卧床、床头墙、吊灯和床头柜来自用户套房，保持原始尺寸。规划碰撞将床、床头墙和床头柜分开；地毯可行走，不能把整个组的大包围盒当成实体障碍。
- 次卧模块分别用 1.50m 与 1.35m 床，每间有衣柜与学习桌。桌前椅子和衣柜正面必须保留可用空间，不能只检查桌板占地。
- 厨房西侧工作台的冰箱挪至南端，北侧水槽台压低挡水背板，避免遮挡窗。02 镜像后做相应反向操作。
- 家政柜放在主卧窗与客厅阳台门之间的实墙下，包含洗衣机、烘干机和独立盆；01 实际网格投影调整为 x3.35..4.635 / y−0.968..−0.26，02 对称镜像。原西侧线性花槽横移 −2.60m 至旧家政位置，圆盆和餐桌椅保持原位；雨棚一起重定位。此次坐标选择以初版 `actual-mesh-audit.json` 的真实物件包围盒检查，平移后家政组与 137 个阳台网格无 3D 包围盒相交。
- 阅读书柜靠南墙实墙段：01 为 x13.12..15.02 / y0.24..0.64；02 为 x0.58..2.48 / y0.24..0.64。不得移到东/西侧长窗前。
- `viewer` 含专用机位顺序、说明、漫游边界和补光数据。`viewer.lighting.powerScale=0.13` 仅供 Three.js 补光强度换算，不影响 Blender 面光瓦数。

## 规划检查

数据内 `planning_validation` 保存结果与限制，`walk_paths` 保存入口到每个分区的路线。两套均通过：

- 恰好 3 间卧室、2 间卫浴；3 间卧室均有外窗。
- 分区无重叠，含墙分区面积相加均为 179.40㎡。
- 门窗开口处于所属墙线内，开口之间无重叠。
- 使用 50mm 网格、人物半径 300mm，加入墙体、已打开门扇、阳台停放玻璃以及家具规划实体，入口可达全部 12 个分区目标。
- 厨房和公卫真正改变入口后，02 的路径单独重算，不复用 01 路径。

这些是平面规划结果；最终交付还须读取 Blender 求值后的真实网格检查穿墙、窗前遮挡、入口和淋浴区可达性。模型运行时自由漫游与这个离线规划检查不是同一套碰撞系统。最终检查记录应以交付目录中的 `actual-mesh-audit.json` 为准。

## 资产与接入边界

用户提供的套房家具及其中图片属于用户资产，不能标为 CC0。橡木、石材等继续使用仓库已有的 Poly Haven CC0 贴图，来源见 `docs/texture-sources.md`。本轮布局不改 `src/` 和园区户型数量；后续接入高层住宅仍需调整楼栋轮廓、核心筒、单元入口与层高，不能缩小整套室内以塞入旧房间。
