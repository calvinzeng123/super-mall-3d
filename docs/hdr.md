# HDR 光影、画质细项和室内光影

2026-11-11。这一轮做了四件事：加了「HDR 光影」模式；把画面设置拆细；商场和住宅里多了光斑、真实的灯和遮蔽；社区住宅、套房在不改布局的前提下更真实一些。FPS（封锁行动）没有动。

## 先说清楚「HDR」指什么

这里的 HDR 是**渲染上的**：光照按真实的亮度范围来算（亮度可以超过 1），反射和环境光来自一张真实天空的 HDR 图，最后再压回屏幕能显示的范围。它**不是**让手机或显示器输出 HDR 信号——网页上的 WebGL 目前做不到这件事，画面仍然是普通的 sRGB。

## 「HDR 光影」开着时有什么不同

| 变化 | 做法 | 花费 |
| --- | --- | --- |
| 天空是真的 | 一张 Poly Haven 的纯天空 HDRI（CC0），白天当背景；入夜渐渐换回原来的渐变夜空和星星 | 一张 2048 × 512 的图 |
| 玻璃幕墙、水面、金属反射蓝天白云 | 室外材质（外立面、幕墙、水面、室外铺装）改用天空的环境图；室内材质照旧用室内环境图 | 没有额外的绘制 |
| 颜色更通透，白色不糊 | 色调映射从 ACES 换成保色的 Neutral；曝光和补光按「在室内还是室外」过渡，像眼睛的适应 | 没有 |
| 石材、木地板、不锈钢更亮 | 这几种材质的粗糙度调低（数值在 `materials.js` 的 `HDR_FINISH`）；地毯、墙面、混凝土不动 | 没有 |
| 灯具白天也是亮着的 | 灯的亮度超过 1，开了高光柔光时会溢出一点光 | 没有 |
| 夜景不再整片发白 | 夜景柔光的阈值抬高，只有灯具和招牌发光 | 和原来的夜景柔光一样 |

只开「HDR 光影」、不开下面两项时，白天**不多画任何一遍**：场景照旧直接画到屏幕。

依赖它的两项（单独的开关，关着 HDR 时置灰）：

- **环境光遮蔽**：墙角、家具脚下、物体交接处自然变暗。只读主画面的深度图来算（法线从深度推出来，场景不重画），每个像素 12 个取样，再降噪。高分屏上按一半分辨率算。
- **高光柔光**：白天亮度超过 1.5 的高光（灯具、阳光下的反光、太阳）溢出一点光。阈值比夜里高，白墙不会发雾。

这两项任意开一项，场景就改为先画进一张半浮点、带多重采样抗锯齿的缓冲，再后处理输出（`src/render/post.js`）。

## 增加的光影

不依赖 HDR 光影、所有档位都有（「贴地阴影与光斑」开着时）：

- **灯下的光斑**：商场走道每盏筒灯正下方的地面有一团暖光（贴花，`BatchSet.pool()`）。夜里更明显。
- **窗边的天光**（社区住宅）：外窗和落地玻璃一侧的地面上有一条从窗边向屋里淡出的光。朝着太阳的一面暖而亮，背阴的一面冷而淡，入夜淡出。

要在设置里打开的：

- **室内灯光**：一小池真实的聚光灯跟着人走（`src/render/indoor-lighting.js`）。商场走道的筒灯、社区住宅各房间的吸顶灯，位置在搭建时记在楼层上；漫游到那一层时挑离人最近的 4 或 8 盏点亮，地面和墙面有真实的明暗，亮面地板上有灯的高光。换灯是渐亮渐灭的，不跳。这些灯不投影。灯亮着时没有方向的补光会压低一些，不然看不出明暗。不漫游、或者那一层没有灯位时，整池隐藏，不占资源。
- **环境光遮蔽**：见上。

## 住宅和酒店

没有改任何户型、墙、门窗和家具的占地（碰撞数据没动）。

**社区住宅（西苑、北苑，338 套，程序化搭建）**

- 墙面和家具从纯色换成带细抹灰纹理的材质（有法线起伏），夜里的亮度和原来一样。
- 每个房间加了平顶和一盏方形吸顶灯。原来抬头看到的是楼板底，夜里是黑的；现在是亮的白顶。平顶和门楣画在同一批里，从上往下俯瞰时一起隐藏，不挡住户内。
- 家具、床脚下垫一团软阴影，实墙墙根有一条渐暗带（门洞、落地窗、开敞的一边不画）。
- 客厅的方块沙发换成布艺沙发模型（拉伸到原来的占地），转角那一段换成脚凳；阳台的盆栽换成盆栽模型。模型包没下载下来时照旧画方块。
- 每层仍是 8 个网格以内、1,500 个盒体以内（西苑 12F 是 1,423）；贴花另算，最多 3 个小网格。

**塔楼住宅（R1–R4）和酒店、公寓套房（GLB 模型）**

- 模型本身没动。HDR 光影下白沙发、白床品的布纹看得出来了（原来曝成一片白），木地板、洞石、石材台面按材质名登记了亮面做法（`app.js` 的 `MODEL_FINISH`）。
- 环境光遮蔽对这两类房间最见效：家具和地面、墙和天花的交接有了深浅。

## 花费

在这台没有显卡的机器上用软件渲染量的（1280 × 800，每帧取 6 次的中位数）。绝对数字没有参考价值——真机的显卡快得多——只看各档之间的比例。

每帧耗时（秒）：

| 机位 | 流畅 | 均衡 | 精细 | 极致 |
| --- | --- | --- | --- | --- |
| 俯瞰全园（240 万三角形） | 3.9 | 5.0 | 5.3 | 5.8 |
| 商场 1F 走道（约 650 万三角形） | 5.2 | 7.7 | 9.3 | 14.0 |
| 西苑客厅（160 万三角形） | 1.9 | 2.3 | 2.4 | 4.1 |

在「精细」上只改一项，耗时的变化：

| 改动 | 俯瞰全园 | 商场 1F 走道 | 西苑客厅 |
| --- | --- | --- | --- |
| 关掉 HDR 光影 | −1.5% | −0.4% | −0.3% |
| 加环境光遮蔽 | +9% | +4% | +26% |
| 加高光柔光 | +2% | +0.3% | +6% |
| 加室内灯光 8 盏 | 室外没有灯，不变 | +41% | +39% |
| 三项都加（就是「极致」） | +10% | +50% | +66% |

- **HDR 光影本身几乎不花性能**：开和关差不到 2%，在测量的波动之内。
- **最贵的是室内灯光**：8 盏灯要让画面里每个像素多算 8 次光照。所以它只在「极致」里默认开，手机上最多 4 盏。
- 环境光遮蔽和高光柔光是按屏幕像素算的固定开销，和场景复杂度无关：场景越简单（客厅），它占的比例越大。
- 后处理管线多出来的是 17 次全屏绘制（俯瞰 1,947 → 1,964 次，客厅 423 → 440 次），三角形数不变。
- 这台机器的像素比是 1，所以「均衡」「精细」「极致」在这里画的像素一样多（「流畅」是 0.85）。在高分屏上「精细」「极致」的清晰度上限是 2，像素数最多是「均衡」的 2.6 倍，这部分开销和以前一样，不是这一轮加的。

- 天空素材两个文件共 208 KB，开了 HDR 光影才下载；单文件版里是内嵌的。

## 实现

| 文件 | 内容 |
| --- | --- |
| `scripts/sky/build-sky.mjs` | 下载天空 HDRI，把太阳转到和场景的平行光同一个方位，生成 `assets/sky/` 下的环境图（256 × 128 的 RGBE，太阳亮度封顶、饱和度压到六成）、天空照片和带出处与校验值的清单 |
| `src/render/sky.js`、`sky-data.js` | 运行时加载；两个构建脚本会把 `sky-data.js` 换成内嵌数据或带校验名的文件 |
| `src/render/env.js` | `setHdr()` 切换色调映射和天空；`grade()` 在画每一帧的时候把曝光、补光乘上调校的倍数（`HDR_GRADE`），画完还原——住宅、套房的灯光模块每帧设的数值不受影响，所以关掉 HDR 画面和以前一模一样 |
| `src/render/post.js` | HDR 管线：场景缓冲 → 遮蔽 → 合成 → 高光柔光 → 色调映射输出 |
| `src/render/materials.js` | `finish()` 登记亮面做法，`outdoor()` 登记室外材质。各栋楼会克隆共享材质（带自己的剖切面），克隆出来的自动登记，昼夜变化时一起跟着变 |
| `src/render/quality.js`、`quality-ui.js`、`src/shell.html` | 设置模型、面板 |
| `src/render/indoor-lighting.js` | 室内灯光 |
| `src/render/build/shell.js`、`residence-interiors.js` | 灯位、光斑、住宅的平顶、贴花和模型 |

重新生成天空素材：

```bash
npm i --no-save sharp
```

```bash
node scripts/sky/build-sky.mjs <放下载缓存的目录>
```

## 已知的限制

- 没有真机测试。软件渲染下的耗时只能看比例；「极致」在手机和集成显卡上多半带不动，所以不是默认。
- 环境光遮蔽是屏幕空间的：隔着玻璃看过去，玻璃后面物体的遮蔽会「印」在玻璃上；屏幕外的东西不参与。
- 室外材质靠登记：外立面、幕墙、水面、室外铺装都登记了；车、桥、摩天轮这些单独建材质的没有登记，它们反射的还是室内环境图（和以前一样）。
- 天空只有白天这一张；太阳的位置是固定的。照片里太阳的仰角是 48°，场景的平行光是 43°，差 5°。
- 室内灯光不投影；一池最多 8 盏，走道很长时远处的灯是不亮的（光斑贴花还在）。
- 社区住宅的沙发只有两种模型，颜色只在模型本色上带一点各户的色调，不如原来的方块沙发颜色多。床、柜子、餐桌还是方块。
- 塔楼住宅和套房没有加窗边天光和吸顶灯位（它们有自己的灯池）。
