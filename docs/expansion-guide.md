# 云澜汇扩建区使用说明

使用新版 Chrome、Edge 或 Safari 打开交付包中的 `mall.html` 即可离线浏览。源码工程生成的同一文件位于 `dist/mall.html`，Three.js、贴图及三套住宅模型都已打包进去。模型解压需要浏览器支持 `DecompressionStream`。

## 从哪里进入

顶部楼栋栏可以选择酒店、公寓和住宅 1 至 4，再用楼层栏查看指定楼层。楼层较多时上下滚动，点「全楼」恢复外观。

| 楼栋 | 位置与主入口 | 地上布局 |
|---|---|---|
| H 云澜酒店 | 一期西侧，东侧主入口朝向方庭 | 20 层，每层 10 间，共 200 间 |
| A 云澜服务公寓 | 酒店南侧，东侧主入口 | 20 层，每层 10 间，共 200 间 |
| R1 至 R4 云澜汇楼盘 | 二期星湾后区，南侧主入口朝向商场 | 每栋 30 层；1F 大堂，2F–30F 每层 3 户，共 348 户 |

六栋塔楼的全部楼层可进入，包含地下层和屋顶。合计 748 间客房及住宅使用可复用房型模板。住宅每个标准层包含 01 横厅家庭型、02 镜像阅读型两套三房两厅两卫，以及 03 四房两厅三卫；三户均有大阳台。各标准层重复这三套布局。园区远处原有的城市白色楼群是背景装饰，不能进入。

## 住宅标准层与大堂

选择「住宅1」→「2F」可查看三户及公共走廊，选择「30F」查看高层，选择「1F」查看独立大堂。01/02 位于南侧两翼，03 位于北侧；3.2 米宽公共走廊连接入户门、双玻璃电梯和东西两部消防楼梯。原 Blender 模型按 1:1 放置，住宅的墙、家具和淋浴玻璃参与人物碰撞。

1F 不放住宅，单独布置门厅、礼宾接待、会客等候、信报快递、物业、阅读及卫生间。楼层俯瞰时会剖开顶板，进入室内漫游后恢复室内显示。模型及重建说明见[住宅接入说明](residential-integration.md)。

## 走进房间与乘梯

1. 点工具栏「漫游」，再点击画面控制视角。鼠标无法锁定时，按住画面拖动也可转头。
2. 用 WASD 或方向键行走，Shift 加速，空格跳跃。F 或连续按两次空格切换飞行，飞行时空格上升、C 下降。
3. 走到电梯门正前方，按 E 或点楼层提示选层。新增楼栋的玻璃轿厢会连续升降，到站后继续漫游。飞行模式下先按 F 返回步行，再操作电梯。
4. 消防楼梯保留可进入的门口和平台，走到门口按 E 或点提示换层；目前仍为互动换层，不能逐级步行跨层。
5. 点「地点」打开目录，可快速选择建筑、楼层或房间。Esc 释放鼠标，点「退出」回到俯瞰视角。

普通客房与住宅均设床和独立卫浴，公寓有厨房；住宅保留原样板的床品、厨卫、餐厅、客厅及阳台。园区采用最多三层精装缓存，首次进入某层可能需要短暂加载。

## 地下连通与停车

地下步行主线为住宅 R1 的 B1 → 星湾 P2 的 B1 → 地铁 M 的 B1 → 一期 P1 的 B1M → 酒店 H 的 B1 → 公寓 A 的 B1。R2、R3、R4 的 B1 通过地下支路接入 R1 共享通道。酒店 2F 另有通往方庭 2F 的空中连廊。

酒店、公寓的 B2 车库与一期 P1 的 B1 车库互通。住宅区有独立进出坡道，位于住宅区西北侧，沿北侧环路可达，连接住宅 B1 共享车库。

住宅 B1 南出口的六米车道位于双电梯东侧，沿该侧通道进入住宅地下干道，再转至二期与地铁方向。四栋的停车支路及地面入口均已随新住宅外包络对齐。

## 从源码运行

电脑需安装 Node.js、npm 和 Python 3。在工程根目录依次执行以下命令，首次安装依赖需要联网。

```sh
npm ci
npm run build
npm run serve
```

随后打开 [本地预览](http://127.0.0.1:5174)。改动源码后重新执行 `npm run build`，即可更新页面和 `dist/mall.html`。
